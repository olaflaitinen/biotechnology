# Bibliography

Every citation key used anywhere in this library, resolved to a full reference.

This document is the human-readable rendering of `src/biotechnology/refs/`,
which is the machine-readable source of truth. Every string in every subtype's
`linkage.REFERENCES` resolves to an entry here, and the integrity suite fails
the build if one does not.

---

## How citations are used in this project

**By identifier only.** No abstract, figure, table or passage from any cited
work is reproduced anywhere in this repository. Citing a document by identifier
is not a reproduction of it and does not create a derivative work. See
[`NOTICE.md`](NOTICE.md) §3.3.

**Deliberately sparse.** Each subtype cites roughly five works, not fifty. The
selection pattern used throughout is:

1. the founding paper - where the idea or the tool first appeared;
2. an authoritative modern review - the single best entry point today;
3. the enabling technology paper - what made it practical;
4. a landmark result - the moment it became real;
5. the governing regulatory or standards document.

A reader who follows those five understands the field. A reader handed fifty
references understands that the author read fifty papers.

**Key format.** Lowercase surname of the first author, followed by the year:
`jinek2012`, `kohler1975`. Institutional documents use a source prefix and a
descriptive slug: `ema_atmp_guideline`, `who_trs_vaccines`, `cpic_guidelines`.

## Adding a reference

Add it to `src/biotechnology/refs/`, not to this file - this document is
generated from that package.

Requirements:

- A **DOI** where one exists. A reference without one must justify its absence
  (historical works before DOI assignment, institutional documents with a
  stable URL instead).
- **First-author surname plus year** as the key, or a **source prefix plus
  slug** for institutional documents.
- At least one subtype must cite it. An unreferenced entry is flagged by the
  integrity suite, because an accumulating bibliography nobody points at is how
  a curated dataset starts to rot.
